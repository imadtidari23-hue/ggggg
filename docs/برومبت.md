# برومبتات الصور · TikArena

صور الهدايا والأكسيونات كتبان فالهود (دليل الهدايا، الإشعارات) وفـ OBS.
الصفحة كتعطي برومبت لكل تفاعل (زر ✨ برومبت) ولا كلهم مرة وحدة (✨ كل البرومبتات).

## القواعد
- مربعة 1:1، خلفية شفافة (PNG)، الموضوع فالوسط، **بلا كتابة**.
- الصفحة كتصغر الصورة لـ 128×128 وحدها.

## الستايلات (4)
| الستايل | النهاية ديال البرومبت |
|---|---|
| 3D | glossy 3D game icon, soft studio lighting, vibrant colors, rounded shapes, high detail, centered, isolated on a transparent background, no text |
| Neon | neon glow icon, dark background, cyberpunk style, bright outline in electric green and blue, centered, simple silhouette, no text |
| Cartoon | cute flat cartoon sticker, thick white outline, bold colors, playful, centered, transparent background, no text |
| GTA | GTA V loading screen art style, comic illustration, strong ink lines, dramatic shading, centered subject, transparent background, no text |

## الشكل
- **الأكشن:** `Square 1:1 icon of <الموضوع>, <الستايل>.`
- **الهدية:** `Square 1:1 icon of the TikTok LIVE gift "<اسم الهدية>" (<إيموجي>), <الستايل>.`
