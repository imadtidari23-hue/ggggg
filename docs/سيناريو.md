# سيناريو المشروع: TikArena · DarkRing Studio

> هاد الملف كيوصف المشروع كامل: الفكرة، والقرارات اللي تاخدات، وكل الإعدادات، والتفاصيل التقنية.
> الهدف ديالو: تعطيه لأي ذكاء اصطناعي جديد باش يفهم المشروع ويكمل عليه، ولا يعاود يبنيه بنفس الطريقة.

---

## 0. كيفاش تستعمل هاد الملف مع ذكاء اصطناعي جديد

1. عطيه هاد الملف كامل.
2. عطيه حتى الملفات ديال الكود من الريبو (هوما المرجع الحقيقي):
   - `src/TikArena.3.cs`: المحرك ديال السكريبت (C#).
   - `src/generator.html`: صفحة المولّد (HTML + CSS + JavaScript).
   - `build.py` و`src/native-hashes.txt`: البناء.
3. استعمل البرومبت اللي فـ **الملحق ب** فالأخير.

> ملاحظة: إلا كان عندو الكود، ما يعاودش يكتبو من الصفر. يبدل غير اللي طلبتي.

## 1. الفكرة العامة

- **المشروع:** سكريبت لـ GTA V (Story Mode فقط، ماشي Online) كيتصل باللايف ديال TikTok عبر **TikFinity**.
- **كل تفاعل من المشاهدين** (هدية، لايكات، بارتاج، فولو، تعليق، اشتراك) كيولي حدث فاللعبة: إنزال أعداء، مساعدين، سيارات، زلزال، علاج...
- **صور البروفايل الحقيقية** ديال الداعمين كتبان فوق راس الشخصيات اللي نزلوهم، وفالهود، وفالإشعارات.
- **التحدي:** «أنا ضد المشاهدين». عداد 10 دقايق: إلا بقيتي حي = فوز، إلا مت قبل = خسارة.
- **المولّد:** صفحة HTML فيها جميع الإعدادات، كتصدر ملف السكريبت `.cs` وملف الإعدادات `.ini` والصور والأصوات فـ ZIP.
- **اسم الواجهة:** DarkRing Studio. **اسم السكريبت:** TikArena.

## 2. التقنيات والقيود التقنية (مهمة بزاف)

| اسم الملف | `TikArena.3.cs`. النهاية `.3.cs` كتقول لـ SHVDN يجمعو بالنسخة 3 ديال الـ API. |
| لغة C# | **C# 5 فقط**: بلا `$""`، بلا `?.`، بلا `nameof`، بلا `=>` فالخصائص، بلا `out var`. SHVDN كيجمع الكود بـ compiler قديم. |
| الترميز | الملف `.cs` كيتحفظ UTF-8 **مع BOM** (باش العربية ما تخربش). |
| الدوال ديال اللعبة (natives) | كتكتب فالكود `Hash.NAME`، و`build.py` كيبدلها بالرقم `(Hash)0x...UL` من `src/native-hashes.txt`، باش السكريبت ما يتعلقش بنسخة معينة من SHVDN. |
| المراجع (References) | غير: System، System.Core، System.Drawing، System.Windows.Forms. (WebSocket = `System.Net.WebSockets.ClientWebSocket` فـ System.dll، والصوت = `System.Media.SoundPlayer`). |

| نسخة DLL | `dist/TikArena.dll` مجموعة بـ mcs كبديل إلا ما خدمش `.cs`. خاص Unblock فالويندوز. |
| التحقق | الكود كيتجمع بـ `mcs -langversion:5` مع `ScriptHookVDotNet3.dll` (NuGet: ScriptHookVDotNet3 3.6.0، ولا الـ release ديال GitHub v3.6.0). |

## 3. هيكلة الملفات

### فالريبو
```
build.py                 ← كيبني index.html و dist/
index.html               ← الصفحة النهائية (فيها المحرك والـ DLL مدموجين)
src/generator.html       ← الصفحة (المصدر)، فيها "%%ENGINE%%" و "%%ENGINE_DLL%%"
src/TikArena.3.cs        ← المحرك (المصدر)
src/native-hashes.txt    ← NAME=0xVALUE لكل native مستعمل
dist/TikArena.3.cs       ← المحرك النهائي (بالأرقام + BOM)
dist/TikArena.dll        ← النسخة المجموعة
docs/سيناريو.md          ← هاد الملف
docs/برومبت.md           ← برومبتات الصور
```
البناء: `SHVDN_REF=/path/ScriptHookVDotNet3.dll python3 build.py` (بلا SHVDN_REF كيستعمل الـ DLL اللي كاين).

الـ DLL ديال SHVDN: `https://github.com/scripthookvdotnet/scripthookvdotnet/releases/download/v3.6.0/ScriptHookVDotNet.zip` (فيه `ScriptHookVDotNet3.dll`). على لينكس: `apt-get install mono-mcs libmono-system-windows-forms4.0-cil`.

### فالـ ZIP اللي كتصدرو الصفحة
```
scripts/TikArena.3.cs
scripts/TikArena.ini
scripts/TikArena/images/i1_gift.png, i1_action.png ...
scripts/TikArena/sounds/kill.wav, death.wav   (إلا طلعهم المستعمل)
Alternative-DLL/TikArena.dll
OBS-overlay.html
README-INSTALL.txt
TikArena-settings.json
```

### فاللعبة (GTA V\scripts\)
- `TikArena/cache/` صور البروفايل (كتتحمل وكتتحول لـ PNG دائري بوحدها).
- `TikArena/gifts-log.txt` وضع التعلم (اسم الهدية + ID + الكوينز).
- `TikArena/errors.txt` الأخطاء. `TikArena/log.txt` (إلا تشعل DebugLog).

## 5. الاتصال بـ TikFinity

- WebSocket: `ws://localhost:21213/` (قابل للتغيير)، إعادة الاتصال كل 5 ثواني.
- الرسائل: `{"event":"gift","data":{...}}`. القراءة متسامحة: كيقلب على الحقول بالاسم فأي مستوى.
  - المستعمل: `uniqueId` / `userId` / `username`، الاسم: `nickname`، الصورة: أي حقل فيه `profilePicture` ولا `avatar` وفيه رابط.
  - الليفل: `gifterLevel` / `level` / `payGrade` / `userLevel`.
  - الهدية: `giftName`، `giftId`، `repeatCount`، `repeatEnd`، `giftType`، `diamondCount`.
  - الأحداث: gift، like (`likeCount`)، chat/comment (`comment`)، follow، share، subscribe، social (`displayType`)، member/join.
- **الكومبو:** للهدايا اللي `giftType == 1`، السكريبت كيحسب الفرق بين `repeatCount` الحالي واللي قبلو، باش كل هدية تتحسب مرة وحدة.
- **الكوينز** = `diamondCount × العدد`، وكيتجمعو لكل داعم (لـ Top 3 والملك).
- **وضع التعلم:** كل هدية كتتكتب فـ `gifts-log.txt` بالاسم والـ ID الحقيقيين (مرة وحدة لكل هدية فكل جلسة).
- **المطابقة:** بالاسم (بلا فرق بين الحروف الكبار والصغار) ولا بالـ ID.
- **صور البروفايل:** كتتحمل فـ thread بوحدو. إلا كانت `.webp` كيجرب `.jpeg`، ومن بعد كتتحول لـ PNG 128×128 (دائرة ولا مربع).

## 6. التفاعلات (Interaction)

كل تفاعل فيه:
- **الأساسي:** مشعول/مطفي، الاسم، الأكشن، نوع التفاعل (Gift, Likes, Share, Follow, Comment, Subscribe, Key).
- **الهدية:** الاسم + الـ ID (اختياري) + صورة الهدية. اللايكات: «كل شحال من لايك» (كتتجمع لكل شخص). التعليق: الكلمة. مرة وحدة لكل شخص (للفولو والبارتاج...).
- **العدد (Units):** شحال كينزل ولا شحال من مرة، من 1 حتى 999. **ضرب فالكومبو:** Rose ×5 = 5 مرات.
- **الانتظار (Cooldown)** بين كل مرة (الطابور كيتسنى، ما كيضيع والو)، و**زر التجربة**.
- **الشكل:** صورة الأكشن، تأثير النزول، جملة الإشعار (`{name}`، `{count}`)، يبان فدليل الهدايا، كاميرا الدخول.
- **للشخصيات:** السكن (Model)، السلاح، الدم (نقاط حقيقية، اللعبة كتزيد 100)، الدرع، الدقة، مستوى القتال (0-2)، الشراسة (0 واقف، 1 دفاعي، 2 هجومي، 3 انتحاري)، سرعة الضرب، المسافة، الرصاص، علامة فالخريطة، الطوموبيل (للطاقم).
- **حسب الأكشن:** المدة، نقاط +HP، الطقس، عدد الطوموبيلات فالثانية.
- **الصور** فالصفحة كتكون ولا صورة مطلعة (PNG) ولا إيموجي. فالتصدير الإيموجي كيتحول لـ PNG.

## 8. الشخصيات والعالم

- **مجموعات العلاقات:** `TIKARENA_ENEMY` كيكره اللاعب والمساعدين. `TIKARENA_ALLY` صاحب اللاعب وكيكره الأعداء.
- **العدو:** `TASK_COMBAT_PED` ضد اللاعب، وكيتعاود كل 4 ثواني (إلا ما كانش فالقتال).
- **المساعد:** عضو فالمجموعة ديال اللاعب (`SET_PED_AS_GROUP_MEMBER`) و`TASK_COMBAT_HATED_TARGETS_AROUND_PED`. (المجموعة فاللعبة فيها حد ~7؛ اللي زايدين كيتبعو اللاعب بـ `TASK_FOLLOW_TO_OFFSET_OF_ENTITY`.)
- **البوليس كيتجاهل اللاعب:** بلا نجوم (`SET_MAX_WANTED_LEVEL 0`)، ومجموعات COP/ARMY/SECURITY كيحترمو مجموعاتنا.
- **العصابات** (AMBIENT_GANG_*) كيتجاهلو.
- كلشي كيرجع كيفما كان ملي كيتطفا السكريبت.
- **فوق الراس:** صورة البروفايل + الاسم (أحمر للعدو، أخضر للمساعد) + شريط الدم. سيارة المافيا: غير السائق كيبين فوق السيارة.
- **الجثث** كتتمسح من بعد ثانيتين (قابل للتغيير، 0 = مباشرة من بعد الدخان).
- **ما كيضيع حتى واحد:** إلا بعد عدو بزاف (> 300 متر، مثلاً من بعد ما ترجع من السبيطار) كيتمسح وكيرجع للطابور.

## 9. الطابور

- **كلشي كينزل وما كيضيع حتى واحد.** إلا صيفط شي حد 20، كينزلو 20.
- **أقصى عدد فنفس اللحظة:** 15 عدو (من 1 حتى 100)، و10 مساعدين. الباقي كيتسنى، وكلما مات واحد كيدخل الموالي. (سيارة المافيا = 4، الموطور = 2.)
- الترتيب: الداعم الأول كيكمل الدفعة ديالو، من بعد التاني.
- جوج ديال الطوابير: واحد للإنزال (فيه الحد الأقصى)، وواحد للأحداث الفورية.
- الوقت بين كل نزول: 400ms. أقصى عدد لكل هدية: 0 = بلا حد.
- الطابور كيكمل للجولة الجاية (إلا ما تشعلش «مسح الطابور فنهاية الجولة»).

## 10. التحدي

- **الجولة:** 10 دقايق (قابل للتغيير). كتبدا بـ F3، وكتعاود أوتوماتيكياً.
- **الفوز:** بقيتي حي حتى سالا العداد. **الخسارة:** مت قبل. «قتل مفاجئ» كيتحسب خسارة.
- **السلسلة:** «3 انتصارات متتالية» كتبان فالهود.
- **النتيجة ما كتتحفظش:** كترجع 0 ملي تعاود تدخل للعبة (هادا قرار ديال المستعمل).
- **شاشة النهاية:** فوز / خسارة كبيرة مع **MVP** بصورة البروفايل:
  - فالفوز: الداعم اللي عاونك أكثر (مجموع الكوينز ديال أكسيونات المساعدة).
  - فالخسارة: الداعم اللي العدو ديالو قتلك.
- **الشخصية ديالك:** 1000 نقطة دم افتراضياً (اللعبة كتزيد 100)، و100 درع.
- **العداد** كيوقف وقت الكاميرا السينمائية ووقت الإيقاف المؤقت.

## 11. الهود

### اللوحات (كل وحدة كتطفا وكتبدل البلاصة ديالها)
1. **الفوز والخسارة** (فوق فالوسط): العنوان «حاول تقتلني»، والفوز فاليسار (أخضر)، والعداد فالوسط، والخسارة فاليمين (أحمر)، والسلسلة. الترتيب ديال الخانات كيتبدل، وكل خانة كتطفا.

4. **دليل الهدايا** (وسط يسار)، 3 ديال الأشكال:

5. **الإشعارات** (تحت يمين): «قام أحمد بإعطاء سيارة» مع صورة البروفايل وصورة الهدية.
6. **Kill Feed** (وسط يمين): صورة الداعم + «{name} قُتل».
7. **رسائل الحماس** (فوق يمين).
8. **فوق راس الشخصيات:** الصورة، والاسم، وشريط الدم، والعلو.

## 24. التحديث 3: العربية فالهود (أسماء الداعمين وكل الكتابة)

- **المشكل:** الخطوط ديال GTA (ChaletLondon...) ما فيهاش الحروف العربية، داكشي علاش الأسماء والجمل العربية ما كانوش كيبانو.
- **الحل (`[Hud] TextMode=Auto`):** أي كتابة فيها حروف ما كيعرفهاش GTA (عربية، ولا لغات أخرى) كتترسم **مرة وحدة** بـ GDI+ ديال Windows (كيربط الحروف العربية وكيكتب من اليمين لليسار) فصورة PNG بيضاء بحواشي وظل (`TikArena/cache/text/`)، ومن بعد كتترسم كـ sprite ملون. الكتابة اللاتينية كتبقى بخط GTA.
- **الجمل فيها أسماء** (الإشعارات، Kill Feed، الحماس، العدادات): كتتقسم لأجزاء (النص الثابت + الاسم + الرقم) باش عدد الصور يبقى محدود، وكتترتب من اليمين لليسار إلا كان فيها العربية.
- **الرسائل ديال الحالة** («TikArena جاهز»، «تحدثات الإعدادات»...) ولاو كيترسمو بنفس النظام (ماشي subtitles ديال GTA).
- **الأسماء المزخرفة** ديال TikTok (𝓐𝓶𝓲𝓷𝓮، Ａｍｉｎｅ، Ⓐ) كتولي حروف عادية (`FancyToAscii`)، والإيموجي كيتحيد (`StripEmoji`) حيت ما كيبانوش.
- **الاحتياط:** إلا وصل عدد الصور `MaxTextTextures` (1500) ولا فشل الرسم، الاسم كيتحول لحروف لاتينية (أحمد → Ahmd، سارة → Sara). `TextMode=Latin` = دائماً لاتيني. `Off` = بحال قبل.
- الإعدادات: `UnicodeFont` (Segoe UI افتراضياً، أي خط مثبت فـ Windows)، `UnicodeBold`، `UnicodeSize` (باش تساوي الحجم مع خط GTA).
- **خاصها تجربة فاللعبة:** الحجم والبلاصة ديال الكتابة المرسومة مقارنة مع خط GTA.

## 25. التحديث 4: تصاميم LiveHud (7 أشكال) + برومبت كيتبع الأكشن

### LiveHud (مدموج فـ `TikArena.3.cs`، namespace `LiveHudKit`)
- الكيت ديال «PENALTY LIVE» (الملف `LiveHud.cs` اللي جاب المستعمل) تزاد كامل داخل السكريبت، مع تعديلات صغار:
  روابط الصور كتقبل لائحة (`\n`)، Referer، `TikArena.Wic` كاحتياط لـ WebP، إعادة المحاولة إلا كانت الصورة حرف، و`BallIcon` بلاصت الكرة.
- **7 تصاميم:** arena · broadcast · podium · cards · esports · minimal · classic. **5 ألوان:** GOLD · NEON · FIRE · ICE · CLASSIC. الخطوط: default sport gta modern elegant mono fun custom.
- **الربط مع TikArena:**
  | الكيت | TikArena |
  |---|---|
  | TOP SCORERS (goals) | أفضل الداعمين بالكوينز (`AddGoal` على كل هدية) |
  | NEXT SHOTS (balls) | الطابور: سطر لكل داعم بالترتيب، وحدة لكل عدو/أكسيون، الأيقونة = صورة الأكشن (`UnitIcon`) |
  | RESULT banner | الفوز (أخضر) / الخسارة (أحمر) مع MVP بالصورة |
  | MEGA GIFT | هدية ≥ `MegaMinCoins` (1000) |
  | SWAP gift | «هدية مميزة» تحت يسار (تفاعل محدد، مطفية فالأصل) |
- `ReplaceTop3` / `ReplaceEndScreen`: كيعوضو اللوحة والشاشة القديمة. الوضع 9:16 كيتبع F7 (tiktok).
- الأزرار: `DesignKey=F10` (التصميم الموالي)، `StyleKey=F5` (اللون الموالي).
- القسم `[LiveHud]` فالـ INI، وفالصفحة: 5 مجموعات فـ 🖥️ الهود + أزرار سريعة «🏟️ تصاميم LiveHud» تحت المعاينة (المعاينة تقريبية).
- Kill Feed ولى افتراضياً تحت يسار (باش ما يتغطاش بلوحة الطابور).

### البرومبت كيتبع الأكشن الحالي
- ✨ برومبت كيتولد من الإعدادات الحقيقية ديال التفاعل: السكن (`SKIN_EN`)، السلاح (`WEAPON_EN`)، الطوموبيل (`VEH_EN`)، العدد، +HP، المدة، الطقس.
- مثال: عدو مهرج بـ `WEAPON_MICROSMG` → «a hostile evil circus clown holding a compact micro SMG»؛ بدلتي لـ `WEAPON_CARBINERIFLE` → «... holding an M4 carbine assault rifle»؛ بدلتي السكن لسوات → «a hostile SWAT officer ...».
